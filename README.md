# campus-secondhand-python
本项目是基于 Django 5.2 + Jinja2 + MySQL 重写的武汉理工大学校园二手交易平台，由原 Java Spring Boot 版完整迁移而来。平台面向本校学生，提供闲置商品发布、分类浏览、关键词与价格搜索、评论互动、商品下架与售出标记等交易功能；用户侧支持手机号注册登录、个人中心、头像设置、关注粉丝及界面字体调节；买卖双方可通过站内私信沟通，手机号、QQ、微信等联系方式需双方同意后才会互相可见，兼顾效率与隐私；后台提供用户冻结、商品管理等运营能力，另有可选的智能导购机器人。重写中修复了原版水平越权、无 CSRF 防护、多步写库无事务、假「下架」按钮等 36 处缺陷，并经代码复审完成第二轮 11 处安全与数据一致性加固，全部通过真实数据库冒烟测试
